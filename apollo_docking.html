Apollo Docking Simulator

Objective:

Dock your Lunar Module (LM) with the orbiting Command Module (CSM)

How to Dock:

1. Fly UP to reach the blue CSM ORBIT line
2. Match CSM horizontal speed (press → until Rel Vel X is green)
3. Approach the flashing docking port from BELOW
4. Slow down (both velocities must be green to dock safely)

Controls:

↑ Main Engine (thrust UP)
↓ Thrust DOWN (slow ascent)
← → Thrust LEFT/RIGHT (match CSM speed)
P / ESC - Pause | T - Trophy Room

Visual Guides:

• Gray line = your predicted trajectory
• Blue circle + arrow = docking port location
• Green = safe velocity | Red = too fast
